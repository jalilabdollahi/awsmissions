A Query needs an equality condition on the partition key of the table or index it targets. The question "region = X and shippedAt > Y" matches a GSI with partition key region and sort key shippedAt (number). On the IAM side, replace the Scan permission with Query, and remember that an index is its own resource: its ARN ends in /index/<name>. On real AWS a policy that only names the table does not cover it, so list both ARNs. Do not grant any action except the one the job needs.
