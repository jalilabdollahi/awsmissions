A template parameter is an input. If it declares a Default, CloudFormation uses that when you do not supply a value; if it has no Default, the caller must pass a value on every create or update, otherwise the request is rejected up front.

You have two legitimate options: bake a default into the template, or provide the value when you run create-stack. Think about which one suits a template that is meant to be reused by every bakery branch.
