A parameter's type is set when it is written. SecureString parameters are encrypted with a KMS key (the AWS-managed alias/aws/ssm unless you name another one); String parameters are stored as readable text, and you cannot "enable encryption" on an existing parameter in place. What you can do is write the parameter again with the new type, using the overwrite option so that the same name gets a new version. Reading it back with decryption must still give the original value, so carry that value over.
