Two things are missing. The preflight request is an OPTIONS call that the API doesn't answer; a MOCK integration can answer it with no backend and headers mapped in the integration response. The real GET response also needs Access-Control-Allow-Origin, otherwise the browser throws the body away. Static header values must be wrapped in single quotes inside the response-parameters, and the origin must be the exact one (not *), because the app sends credentials. Don't forget to redeploy.
